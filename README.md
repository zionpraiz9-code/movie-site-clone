# Moviee

A responsive movie-streaming landing page built with HTML and CSS. It showcases featured titles, genres, trending movies, and TV shows.

## Live Demo

[View Moviee](https://movie-streaming-site-wine.vercel.app/#)

## Run Locally

Clone the repository and open `index.html` in a web browser. No build step or package installation is required.

## Project Files

- `index.html` — page structure and movie content
- `style.css` — desktop styles
- `phone.css` — responsive styles for smaller screens
- `Images/` — image assets used by the page
